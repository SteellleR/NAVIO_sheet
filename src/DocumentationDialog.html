Если контрольная дата не обновлена больше четырёх дней и лог ещё не заполнен, адрес строки появляется напротив телеоператора.

Быстрая помощь

Частые вопросы

Не появилось меню NAVIO

Полностью перезагрузи вкладку с таблицей. Если меню всё ещё нет, открой «Расширения → Apps Script» и обратись к разработчику.

Не появилась ссылка «Добавить лог»

Проверь, что в строке есть корректная дата события и ВАТС. Затем измени любую ячейку этой строки. Если не помогло — сообщи разработчику лист и номер строки.

После изменения справочника нет нового логина

Немного подожди: таблице нужно время на обновление — обычно до 10–20 секунд. Если логин так и не появился, запусти «NAVIO → Установить или обновить проект». Не добавляй логин вручную в каждый рабочий лист.

Ошибка уже исправлена, но осталась в «Нарушителях»

Обычно строка исчезает спустя 20–30 секунд после изменения. Для контрольной проверки или если таблица так и не обновилась запусти «NAVIO → Полный пересчёт нарушителей» и дождись завершения.

Точка входа

Выбери способ сопровождения проекта

Это bound-проект Google Apps Script на JavaScript V8. Он обслуживает рабочие строки, синхронизирует нативные dropdown-столбцы и строит обратимый отчёт по просроченным логам.

Работаешь через обычный ИИ-чат?

Открой блок «Для ИИ», выбери нужный промпт и скопируй или скачай его. Модель будет вести тебя по интерфейсу Apps Script пошагово.

Уверенно работаешь с JavaScript и HTML?

Переходи к «Продвинутым разработчикам»: там архитектура, триггеры, данные, квоты, тесты и открытый GitHub-репозиторий.

Сопровождение без опыта разработки

Два промпта для обычной чат-модели

Промпты не обязательно читать целиком. Если нужно изменить тексты, внешний вид или устройство документации, выбери «Изменить HTML-документацию». Если нужно добавить, удалить или поменять функциональность и принцип работы скриптов таблицы — выбери «Изменить backend и функциональность». Вставь нужный промпт в свою нейронку и напиши, что хочешь сделать: ИИ сам запросит необходимые файлы и скриншоты, задаст уточняющие вопросы и проведёт тебя по шагам.

!
Внимание!
  1. Промпты большие, поэтому некоторые ИИ-чаты могут не принять их обычным сообщением. В таком случае нажми «Скачать TXT» и прикрепи полученный файл к диалогу — это обычно помогает обойти ограничение по длине сообщения.
  2. После действительно существенных изменений обнови документацию и сам промпт. Это уже заложено в инструкции: просто попроси ИИ помочь, а затем выполни предложенные шаги. Мелкие правки текста, цветов или опечаток переносить во все материалы не обязательно.

Только интерфейс и тексты HTML. Не разрешает модели вмешиваться в серверную логику таблицы.

Критичный сценарий

Одна строка проходит через несколько независимых правил

  • 1Дата события. Новое значение инициализирует контрольную дату. Одиночное исправление переносится только пока пользователь её отдельно не актуализировал.
  • 2Logviewer. По дате и нормализованному ВАТС строится формула HYPERLINK с подписью «Добавить лог».
  • 3Настоящий лог. Ссылка с путём /logs/ переводит контрольную ячейку в «заполнен». Удаление возвращает дату события.
  • 4Нарушение. На пятый день без актуализации адрес добавляется телеоператору; после исправления удаляется.

Производительность

Быстрый edit плюс контрольный полный проход

Инкрементальный режим

Получает только изменённые строки, пересчитывает их адреса и точечно обновляет готовый отчёт. Это основной путь при ручной работе.

Полный режим

Раз в 10 минут получает метаданные нативных таблиц один раз и читает реальные границы таблиц, а не весь размер листа.

Условия

Нарушение существует после четырёх полных дней, только в окне последних 30 дней и только без статуса «заполнен».

Обратимость

Снимок полностью выводится из текущих данных. Исправленный адрес удаляется, пустые хвосты отчёта очищаются.

Google Sheets tables

Шторки обновляются через Sheets API

Spreadsheet service не даёт достаточно удобного управления нативными table-column dropdown. Поэтому проект читает метаданные таблиц и отправляет точечные updateTable.

Телеоператоры

Логины читаются из скрытого справочника, нормализуются, проверяются на дубли и хешируются. Полная замена вариантов поддерживает и добавление, и каскадное удаление.

ВАТС

В шторки попадают только номера со статусом Active. Неизвестный статус и пустой номер активной записи считаются ошибкой данных.

!
Заголовок должен находиться ровно один раз

Код намеренно падает с понятной ошибкой, если лист, нативная таблица или целевой столбец неоднозначны. Не ослабляй эту проверку ради «быстрого фикса».

Состояние проекта

Пауза листа хранится в Document Properties

Ключ active_working_sheets_v1 содержит JSON-массив активных листов. При отсутствии свойства безопасный дефолт — все листы из APP_CONFIG_.workingSheets.

  • 1В рамках одного выполнения список кэшируется в ACTIVE_WORKING_SHEETS_CACHE_.
  • 2Любой профильный обработчик сначала проверяет isWorkingSheetTracked_() и быстро выходит.
  • 3После выключения полный снимок нарушений сразу очищает адреса листа.
  • 4После включения запускается восстановление dropdown, дат, форматирования и ссылок.

Почему широкий Sheets scope

Нативные таблицы и Sheets API требуют полного scope. Код при этом работает только со связанной таблицей и её сохранённым ID.

После изменения scopes

Нужно заново загрузить манифест и один раз повторно авторизовать installProject().

Runbook

Когда нужен installProject

Простая загрузка кода обновляет функции сразу. Переустановка нужна после изменения триггеров, интервала, scopes, dropdown-логики или при первом подключении проекта.

Что делает установка

  • Сохраняет ID связанной таблицы.
  • Удаляет только собственные старые триггеры.
  • Синхронизирует активные листы и справочники.
  • Создаёт edit, change и десятиминутный таймер.

Безопасная публикация

  • Проверить Script ID и tracked files.
  • Сделать резервную копию.
  • Отправить на тест.
  • Авторизовать и проверить сценарии.
  • Только затем повторить на основе.
Типовые сбои

Сначала структура и журнал, потом гипотезы

403 insufficient authentication scopes

Сверь oauthScopes в appsscript.json, отправь манифест и повторно авторизуй installProject(). Для модальных окон нужен script.container.ui.

Не найден лист или столбец

Проверь точное имя, регистр, строку заголовков и отсутствие дублей. Код намеренно не угадывает неоднозначную структуру.

Service Spreadsheets timed out

Не запускай повторно много раз подряд. Проверь параллельные выполнения, размер диапазона и необходимость массовых операций. Основные сканы должны идти по границам нативной таблицы.

Постоянный locked

Один или несколько запусков конкурируют за DocumentLock. Проверь журнал «Выполнения», зависшие задачи и частоту структурных изменений.

Меню или HTML-окно не обновилось

Перезагрузи таблицу для нового onOpen. Если менялись scopes — повторно авторизуй проект.

Чек-лист изменения

Оставь проект понятнее, чем он был до тебя

  • 1Новую константу добавь в APP_CONFIG_, а доменную логику — в профильный файл.
  • 2Внутренние функции заканчивай подчёркиванием; не создавай дубли глобальных имён.
  • 3Минимизируй вызовы Spreadsheet service: читай и записывай диапазоны пакетно.
  • 4Не удаляй чужие форматирования и триггеры; распознавай только принадлежащие проекту.
  • 5Добавь smoke-тест для чистой логики и сценарий ручной проверки для интеграции.
  • 6Обнови локальный README и оба раздела встроенной документации в той же правке.
